# 🚀 Meu Portfólio - Samuel Lazarin

Este é o meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e experiências no desenvolvimento Front-end. O site foi construído com foco em design moderno, responsividade e performance.

---

## 🎨 Design & Estilo

O projeto utiliza uma paleta de cores moderna baseada em tons de roxo vibrante, utilizando as últimas tendências de CSS:

- **Cor Principal:** `#bf48ff` (Magenta/Roxo Vívido)
- **Destaques:** `#b29bf7` (Lavanda Suave)
- **Estilo:** Clean, moderno e focado na experiência do usuário.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica.
- **Sass:** Estilização avançada com Flexbox e Grid.
- **OKLCH:** Gerenciamento de cores de alta fidelidade.
- **JavaScript:** Interatividade e animações.
- **React:** Maestro da interface: ele controla a atualização automática dos elementos e a repetição dos cards de projetos sem precisar escrever HTML repetido.
